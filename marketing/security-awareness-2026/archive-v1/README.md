# האתר עובד. האם הוא גם מוגן?

קמפיין מודעות לאבטחת אתרים ואפליקציות של NG Workshop. הוכן ב־6.9.2026.

## הקונספט

הפער בין אתר שמתפקד לבין אתר שנבדק. הקרוסלה מתחילה בשאלה מוכרת לבעל עסק, מסבירה כיצד AI מקל על חלק מפעולות התקיפה, ומובילה לתהליך מעשי: בדיקה, תיקון ובדיקה חוזרת. המטרה היא פנייה לקבלת הצעה לסריקת אבטחה בתשלום.

העלייה בניסיונות התקיפה מוצגת כתצפית של NG Workshop ללא מספרים. אין ייחוס של התקיפות למודל, למדינה או לסוג רישוי שלא אומתו.
