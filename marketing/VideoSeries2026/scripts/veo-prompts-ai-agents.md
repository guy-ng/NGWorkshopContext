## Universal Style Guide - Apply to ALL Scenes:

**CRITICAL CONSISTENCY REQUIREMENTS:**
- **Background**: Solid deep brown-black (#2A241E) - NG Workshop brand dark background
- **Drawing Style**: Clean vector graphics with precise lines, modern UI style
- **Line Quality**: Thin, crisp lines (1-2px weight), perfect geometric shapes
- **Design Approach**: Geometric, minimalist 2D flat design - rounded rectangles, circles, simple icons
- **Animation Style**: Elements fade in, slide in smoothly - modern motion graphics transitions
- **Camera**: LOCKED - absolutely no camera movement, zoom, or pan
- **Color Palette (NG Workshop Brand)**:
  - Primary: Lime Green (#8ABF3B) - main highlights, connections, glows
  - Primary Dark: (#76A632) - darker lime accents
  - Secondary: Dark Earthy Brown (#3E352B) - secondary elements
  - Secondary Light: (#6B6054) - lighter brown accents
  - Accent: Lighter Lime (#B6D66B) - subtle highlights
  - Text: White (#FFFFFF) - labels and main text
  - Success: Lime Green (#8ABF3B) - checkmarks, confirmations
  - Warning: Orange/Red (#FF6B6B) - errors, warnings only
- **Typography**: Clean sans-serif font (like Inter, SF Pro, or similar), modern and readable
- **Icons**: Simple line icons - rounded rectangles for boxes, circles with symbols, minimalist style
- **Lighting**: Soft lime green glow effects on active elements
- **Borders**: Thin borders (1-2px) with rounded corners (8-16px radius), lime green accent borders
- **Duration**: 3-5 seconds each (short and punchy)
- **Aspect Ratio**: 16:9 (standard video)
- **Resolution**: 1080p minimum
- **Frame Rate**: 30fps

**FORBIDDEN ELEMENTS:**
- No 3D effects or depth
- No complex gradients (subtle glows OK)
- No camera movement
- No realistic textures
- No photorealistic elements
- No complex illustrations
- **NO HUMAN FIGURES OR HANDS** - use abstract icons only (circles, rectangles, symbols)
- No hand-drawn or sketch style
- No chalk/blackboard aesthetic
- No cyan/teal colors - use lime green brand colors only

## Usage Notes:
1. Each prompt is designed for a specific section of the script
2. Keep animations simple and clear - focus on concept communication
3. NG Workshop brand colors create consistent visual identity
4. Can be used as B-roll while narrator speaks
5. Timing can be adjusted in post-production to match narration pace
6. Short durations (3-5 sec) keep videos dynamic and engaging
