# NG Workshop email signature

Brand-only email signature graphic using the current NG Workshop wordmark and the official Camunda Gold Partner Certified badge. The warm paper background, soft browser frame, brand green, and BPMN connector motif are based on the visual language of the NG Workshop website.

## Recommended installation

1. Open `email-signature.png`.
2. Add it as an image in the Gmail or Outlook signature editor.
3. Set the displayed image width to approximately **600 px** (or “original size” if the client already displays it at that width).
4. Link the image to `https://www.ngworkshop.co.il`.
5. Send a test email to Gmail and Outlook and verify it on mobile.

The PNG is exported at 2× resolution for sharp rendering on high-density screens. `signature-source.html` is the editable source. Personal details are intentionally excluded so they can be added as live text by the email client.

## Variants

- `email-signature.png` — original brand-only composition.
- `email-signature-v2.png` — optically balanced version: larger NG Workshop wordmark, smaller Camunda certification badge, and both marks aligned to the same visual center.
- `email-signature-v2.svg` — self-contained SVG of the balanced version with a transparent background. The Camunda badge and layout are vector; the current NG Workshop PNG wordmark is embedded at 2× resolution to preserve the exact approved artwork.
- `email-signature-v2-transparent.png` — transparent PNG export at 1200×300, intended for 600×150 display in email clients.
